# 🎓 CONTEXTE MÉTIER (domain_agent_context)

Ce fichier définit le périmètre technique et humain du projet. Il sert de référentiel pour situer chaque Lab.

## 1. Profil des Apprenants
- **Niveau de Français** : Niveau minimal nécessaire pour lire, comprendre et appliquer les tutoriels.
- **Background** : Ont validé les fondamentaux du Web (HTML/CSS/JS/PHP/SQL).

## 2. La Filière "Développement Web & Mobile" (Solicode)
L'objectif est de former des **Développeurs Fullstack** (Clean Code).
- **Projet Fil Rouge** : App complète (Web Public, Web Admin, API, Mobile Android).

## 3. Référentiel de Compétences (C1 à C7 + M8)
*   **C1 (Concevoir)** : Design Thinking (Persona, Proto Figma), UML (Use Case, Classes).
*   **C2 (BDD)** : MySQL, Migrations Laravel, Eloquent relationships, Seeders.
*   **C3 (Back-end)** : Laravel (MVC, Service Layer, API REST), Auth (Laravel UI + Spatie).
*   **C4 (Gestion)** : Git (Branches, PR), Kanban simple.
*   **C5 (Mobile)** : Android (Kotlin / Jetpack Compose) consommant l'API.
*   **C6 (Qualité)** : Tests manuels et automatisés simples (Pest/PHPUnit).
*   **C7 (Déployer)** : Serveur Linux (LAMP/LEMP), mise en prod.
*   **M8 (Veille)** : Exploration (Labs), partage de nouvelles technos.

## 4. Stack Technique de l'Année (Progressive)

### 🟦 N1 - Socle (Imiter)
*   **Back** : Laravel Basic (CRUD simple, Blade, Validation).
*   **Front** : Blade + Tailwind CSS.
*   **Secure** : Auth Basic (Laravel UI), Middleware.

### 🟪 N2 - Robuste (Adapter)
*   **Back** : Laravel Avancé (Service Layer, Events, Upload).
*   **Front** : Blade + **Preline UI** + **AJAX (Fetch) / Alpine.js** (One Page CRUD).
*   **API** : RESTful Resources.
*   **Secure** : Roles (Spatie Permissions).
*   **Mobile** : Android Compose + Retrofit (Consommation API).

### 🟧 MVP - Transposer (Prod)
*   **Objectif** : Produit fini et déployé (Serveur Linux).
*   **Contexte** : Multi-instances.
