# PARTIE 1 : PÉDAGOGIE ACTIVE (ex 04_contexte_pedagogique)

## 1. La Double Compétence (Modèle Hybride 2TUP)
1.  **Le Socle Technique (N1 / N2 / N3) :** Individuel, Progressif (Imiter -> Adapter -> Transposer).
2.  **La Réalisation Professionnelle (Sprints) :** Groupe, Agile, Application Finale.

## 2. Les 3 Niveaux d'Apprentissage

### 🟢 N1 — Imiter (Le Socle)
*   **Concept :** "J'apprends les bases."
*   **Méthode :** Tutoriels pas-à-pas strict.
*   **Livrable :** Projet Technique N1.

### 🟪 N2 — Adapter (Le Projet technique N2)
*   **Concept :** "Je prépare le N3 et je valide mes acquis."
*   **Méthode :** Adaptation par recherche, Live Coding, Réalisation de Labs.
*   **Objectifs :** Minimiser le risque pour N3, Valider la compréhension.

### 🟧 N3 — Transposer (Le Projet Technique / 2TUP)
*   **Concept :** "Je finalise le Socle Technique."
*   **Méthode :** Prototype générique complet (Architecture avancée).

## 3. Types de Ressources Associées
*   **N1** : Tutoriel Pas-à-Pas.
*   **N2** : Exercice d'Adaptation.
*   **N3** : Conception générique.

## 4. Règles d'Or pour l'IA
1.  **Strict Respect du Niveau** : N1 (Solution complète), N2 (Piste), N3 (Conseil Archi).
2.  **Cohérence Fil Rouge** : Tout s'inscrit dans le contexte du projet global.
3.  **Encouragement** : Valoriser la satisfaction (N1), la confiance (N2), l'autonomie (N3).

Apprenants ayant validé "Développement Web" (HTML/JS/PHP/SQL). Prêts pour l'industrialisation.

# PARTIE 3 : CONTEXTE LABS (ex 06_contexte_lab)

## 1. Définition
Un **Lab** est une unité d'exploration autonome pour apprendre une techno (ex: Alpine.js). Plus léger qu'une Session.

## 2. Structure d'un Lab
1.  **Présentation (Marp)** : Introduction, Diction, Exemples.
2.  **Plan des Tutoriels (3 étapes max)** :
    *   1. Introduction (Hello World).
    *   2. Intermédiaire (Concepts Clés).
    *   3. Exemple Prêt-à-l'emploi (Real World, intégrable au fil rouge).

## 3. Conventions
*   **Dossier** : `labs/lab-[nom]`.
*   **Autonomie** : Exécutable indépendamment.
