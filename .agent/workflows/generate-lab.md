# WORKFLOW: Génération de Lab Solicode

1.  **Analyse du Contexte :** Lire le fichier `README.md` (ou `lab.md`) pour comprendre l'objectif.
2.  **Mapping Compétences :** Identifier la compétence (C2 pour le Front, C3 pour le Back) dans `.agent/resources/referentiel-competences.md`.
3.  **Génération des Tutoriels :**
    - Créer le fichier `00-introduction.md` (Pourquoi Alpine.js vs jQuery).
    - Créer les fichiers `01` à `04` avec des exemples de code progressifs (conforme à `alpine-guidelines.md`).
4.  **Conception du Mini-Projet :**
    - Rédiger l'énoncé du "CRUD Filtrable" (ou sujet du lab).
    - S'assurer que la stack Tailwind + Alpine est respectée.
5.  **Output :** Présenter le tout sous forme de liste de fichiers Markdown prêts à être créés.
