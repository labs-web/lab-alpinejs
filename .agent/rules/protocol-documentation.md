# Normes de Documentation

Règles pour garantir la qualité et la maintenabilité de la documentation du projet.

## 1. Intégrité des Données
- **SSOT (Single Source of Truth)** : Une information ne doit exister qu'à un seul endroit.
- **Versionning** : Si applicable, noter les changements majeurs en en-tête des fichiers.

## 2. Structure des Documents
- **Titres** : Clairs (H1, H2) et correctement hiérarchisés.
- **Listes** : Privilégier les listes à puces pour la lisibilité.
- **Complexité** : Éviter les tableaux Markdown complexes sauf urgence ou demande spécifique.
