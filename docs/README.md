# Documentation des Tutoriels Alpine.js

Ce dossier contient les ressources pédagogiques pour l'apprentissage du framework Alpine.js. Voici la description des trois premiers tutoriels disponibles :

## [Introduction Rapide](./00-introduction-rapide.md)
**Objectif :** Une présentation rapide de Alpine.js sans entrer dans le détail.
Idéal pour comprendre le "pourquoi" et le "comment" en un coup d'œil avant de plonger dans le code.

## [Tutoriel 1 : Initialisation & Réactivité](./01-initialization.md)
**Objectif :** Installer Alpine via CDN et créer un premier composant réactif.
Ce premier module pose les bases en montrant comment intégrer Alpine.js dans une page web et initier la réactivité des données.

## [Présentation Complète](./02-presentation-complete.md)
**Objectif :** Une présentation complète et approfondie du framework.
Ce guide détaille l'ensemble des concepts clés et la philosophie d'Alpine.js pour une maîtrise globale après la première manipulation.

## [Tutoriel 2 : Interactivité](./03-interactivity.md)
**Objectif :** Gérer les évènements utilisateur et la visibilité des éléments.
Ce tutoriel approfondit les interactions en apprenant à écouter les actions de l'utilisateur et à manipuler l'affichage des éléments en conséquence.

## [Tutoriel 3 : Données Asynchrones](./04-async-data.md)
**Objectif :** Consommer une API externe avec `fetch` et `x-init`.
Ce module aborde la communication avec des services externes, essentielle pour charger des données dynamiques dans vos applications.
