# Introduction Rapide à Alpine.js

## Objectif
Comprendre ce qu'est Alpine.js en moins de 2 minutes.

## En bref
Alpine.js est un framework JavaScript minimaliste qui vous permet d'ajouter de l'interactivité à votre balisage HTML à moindre coût. C'est comme Tailwind pour le JavaScript.

*   **Léger** : Quelques ko seulement.
*   **Simple** : Pas de build tools nécessaires.
*   **Puissant** : Réactif et déclaratif.
